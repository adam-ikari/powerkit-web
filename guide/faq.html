常见问题 ​

设置页显示「未检测到联想电源管理驱动」 ​

自动限充走的是联想驱动提供的本地接口，没装驱动就无法下发阈值。打开设备管理器 → 系统设备，确认有 Lenovo Power and Battery（旧名 Lenovo Power Manager）；没有的话先装 联想电源管理驱动，装完重启程序。

其他功能（仪表盘、自动亮度）不受影响。

和 Vantage 同时开着会怎样 ​

两边都能改阈值，会互相覆盖。以 PowerKit 的设置为准：你在 Vantage 或 BIOS 里手动改过的 阈值，会在 PowerKit 的下一个监测周期被改回配置值。想彻底交还给 Vantage，用托盘菜单的 「恢复默认充电策略」或直接在设置页关掉自动限充。

「临时解除限充」什么时候会自动恢复 ​

点一次临时解除后，本次插电期间不再自动限制；重新充满电或拔掉电源之后会自动恢复管理。 这个状态跨重启保留，避免忘了改回而长期满充。想马上恢复，用托盘菜单的「立即启用限充」。

亮度调得很慢 / 不响应 ​

按设计如此：自动亮度要连续两次采样一致才下发，且有死区，确认后还要按每 300ms 走 1% 渐变到位， 避免在临界光照下反复跳。采样节奏本身是自适应的——环境在变时约 12 秒一次，稳定后最长退到 5 分钟， 所以长时间没动静多半是环境确实没变。若亮度完全没变化，先确认这台机器有可用的亮度控制通道（运行 powerkit.exe --selftest 会报告 WMI / DDC/CI 的探测结果）。

盖上防窥拨片会不会把屏幕调到最暗 ​

不会。环境光读数恰好为 0 时判定为镜头被物理遮挡——真实房间里屏幕自身、键盘背光的光总会进到 镜头，读数只会是个小的正数，落到 0 只可能是进光口被挡死。这时屏幕亮度与键盘背光都保持当前值， 不再按这份读数调节；设置页显示「镜头被遮挡 · 亮度保持」，摄像头被系统在隐私设置里禁用或被其他 程序占用时显示「摄像头不可用 · 亮度保持」。遮挡期间仍会定期复查（间隔最长约一分半钟）， 拿开遮挡物后会自动回到快档继续调节；如果你人在屏幕前，通常几秒到一分多钟就能恢复。

想当场确认，运行 powerkit.exe --selftest，它会直接报告「可用（环境光 x/255）/ 镜头被遮挡 / 不可用」。

机器自带光线感应器时为什么这个开关是灰的 ​

有 ALS 时 Windows 自带的自动亮度更准，PowerKit 会主动让位，不再占用摄像头做采样。

日志在哪里 ​

  • debug 构建：实时写 %APPDATA%\PowerKit\powerkit.log，超过 1 MB 轮转；
  • release 构建：默认不落盘，日志只在内存里，设置页点「导出日志」才生成文件并打开；
  • 崩溃信息（PANIC）例外，始终落盘，否则无从排查。

怎么确认版本 ​

设置页第五个页签「关于」显示版本号与版权；powerkit.exe --selftest 的输出头部也带版本。

会不会联网、会不会上传数据 ​

都不会。程序与本机接口对话（电源状态、联想驱动的本地 RPC、WMI/DDC 亮度、摄像头取帧）， 不访问网络、不上传数据；相机画面只用于算一个环境光数值。配置只写在 HKCU\Software\PowerKit，便携版与安装版共用同一份。

装完怎么开机自启 ​

设置页 →「通用」→ 勾选「开机自动启动」，写入 HKCU\Software\Microsoft\Windows\CurrentVersion\Run；取消勾选即移除，卸载时也会清掉。
