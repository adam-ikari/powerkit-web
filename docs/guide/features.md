# 功能详解

## 满电静置自动限充

笔记本**电量充满**（≥95%，照顾标定偏差到不了 100% 的旧电池）后继续插电超过设定时长
（默认 **30 分钟**）时，自动把充电阈值设为 **75%–80%**：电量到 80% 停止充电，低于 75%
才重新充电，与联想 Vantage 的「自定义阈值」一致。拔掉电源自动恢复默认（不限制）。

| 场景 | 行为 |
| --- | --- |
| 充满后插电达到设定时长 | 下发充电阈值 75%–80%（计时从满电那一刻起，掉到 95% 以下或拔电即作废） |
| 电量未充满 | 不限充，状态行显示「已插电，等待电量充满（充满后开始计时）」 |
| 拔掉电源 | 恢复默认充电策略；重新插电重新计时 |
| 临时解除限充 | 立即恢复默认，本次插电不再自动限制；**重新充满电或拔掉电源后**自动恢复管理（跨重启保留，防止忘记改回） |
| 立即启用限充 | 手动立即生效，并取消临时解除状态 |
| 未检测到联想电源管理驱动 | 无法控制阈值，设置页会有红色提示 |

设置页可调：充电上限（默认 80%，范围 50–100）、生效时长（默认 30 分钟，范围 5–720）、
拔电是否恢复、开机自启。改完即存，配置写在 `HKCU\Software\PowerKit`。

满电静置的计时**跨重启保留**：重启后仍从当初充满的那一刻起算，不会因为重启而重新计时。

## 仪表盘

- 电量与充放电状态；
- 电源功率：由电压 × 电流算出，正数表示充电、负数表示放电；
- 电池健康：满充容量 / 设计容量、循环次数、温度。

## 摄像头感光自动亮度

用前置摄像头当环境光传感器，不需要机器自带光线感应器：

- 环境光读数取连续几帧的中位数，去掉两端 10% 的极端像素，避免一帧噪点或屏幕反光带偏；
- 按感知曲线（gamma 1.2）映射到 20–100% 亮度，可整体偏移 ±20%；
- **采样节奏自适应**：环境在变时约 12 秒采一次，读数稳定后逐步退避到最长 5 分钟；
  人离开屏幕（约 2 分钟无键鼠输入）期间不点亮摄像头，回到座位后立刻恢复；
- **目标连续两次采样一致才下发**（跳变 ≥25 时立即响应），死区取「至少 5% 且不小于当前值的 10%」；
  确认后按每 300ms 走 1% 渐变到位——既不来回抖，也不闪一下；
- **摄像头被遮挡或被禁用时不动亮度**：环境光读数为 0 判定为镜头被物理遮挡（防窥拨片、手指、
  贴纸），取不到画面判定为摄像头不可用；两种情况都保持当前亮度，设置页会注明原因，恢复后继续调节；
- 亮度通道自动探测：WMI 优先、DDC/CI 兜底；**没有可用通道时不会开启相机采样**；
- 机器自带光线感应器（ALS）时该功能自动停用，开关置灰，交给 Windows 自带自动亮度。

相机画面只用于算一个环境光数值，不保存、不上传。

## 键盘背光自动控制

按环境光「暗时开、亮时关」，会记住你手动调过的档位。依赖联想的键盘背光接口，
机型没有该接口时开关置灰并给出提示。摄像头被遮挡或不可用时，背光与屏幕亮度一样暂停调节。

## 浅色 / 深色主题

默认跟随系统深浅色，系统切换时实时跟随；也可以在设置页固定为浅色或深色。

## 设置页五页签

自动限充 / 显示 / 通用 / 状态 / 关于。一次只渲染一张卡，窗口高度按当前页内容自动适配
并平滑过渡；「关于」页显示版本号、版权与第三方组件声明。

## 界面形态

- 无边框飞窗固定右下角，使用系统级圆角（DWM），无系统边框线；
- **左键点击托盘图标**打开飞窗，失焦自动关闭；右上角 ×、Esc 也可关闭；
- 右键托盘出菜单：打开 / 隐藏、立即启用限充、临时解除限充、恢复默认充电策略、退出；
- 单实例：重复启动 `powerkit.exe` 只会唤出已运行实例的窗口；
- 隐藏态工作集约 27 MB，显示态约 39 MB。

## 支持与限制

充电阈值目前只覆盖**联想电源管理驱动**的机型（近年 ThinkPad T / X / P / E 系列及部分
Legion）。华硕、戴尔等其他品牌仍在调研中。手动用 Vantage 或 BIOS 改阈值会被本工具在
下一个周期按配置覆盖——以本工具的设置为准。
